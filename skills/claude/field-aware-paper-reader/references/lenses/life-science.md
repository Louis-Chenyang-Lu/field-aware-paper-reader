# Lens: Life sciences and experimental biology (incl. Nature/Science/Cell-style papers)

**How this community reads.** Biologists read **figures first**. A standard approach: abstract → (introduction if new to the topic) → each figure and its legend together with the matching methods → the results text for that figure → repeat → discussion. Read figures and prose together: plot design, selection and processing can also shape the apparent evidence. In these papers each main figure usually carries one claim, and the panels build the argument step by step.

## Reading order
1. Abstract and the final paragraph of the introduction (the claim).
2. Figure 1 → last figure, each with its legend and the methods it relies on.
3. Results text for each figure, checking it says no more than the figure shows.
4. Discussion: how the authors interpret it and what they admit.
5. Extended Data / Supplementary figures for the controls and replicates the main claim rests on.

## For each main figure (panel by panel)
- **What is shown**: experiment or measurement, organism/cell type/sample, conditions, axes and units, what each colour/mark/group is, sample size (n — biological vs technical replicates).
- **What it shows**: the observation in one plain sentence.
- **Which claim it supports** in the paper's argument, and how the panels build on each other.
- **Is it convincing?** Right controls (positive, negative, vehicle, wild type, sham)? Effect size, not only a p-value? Appropriate statistical test, corrected for multiple comparisons? Representative images versus quantification? Are error bars SD, SEM or CI (and is that stated)?
End with a one-paragraph "figure story": how Figures 1→N together make the paper's argument.

## Questions to answer
- Is the central claim causal (knockout, perturbation, rescue) or correlational? Is there an independent method that confirms it (orthogonal validation)?
- Is the result shown in more than one system/model, and does it transfer to humans if that is claimed?
- Are n and replication adequate, and are the replicates truly independent?
- Do the conclusions in the abstract go beyond what the figures show?
- Are key reagents, strains, code and data available?

## Red flags
- Representative images with no quantification.
- n = 3 with large claims; unclear whether replicates are biological.
- Missing controls for the key experiment.
- Bar graphs hiding the distribution; SEM used to make error bars look small.
- Mechanistic language ("drives", "is required for") supported only by correlation.

## Reporting standards
ARRIVE (animal research), MDAR framework, journal reporting summaries. Use them to check what is missing.

## Write in the "Field lens" section
Figure-by-figure walk-through (full for main figures, one line for supplementary ones) → figure story → strength of the causal chain → missing controls or validations.
