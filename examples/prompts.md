# Prompt templates

Replace everything in `<angle brackets>`.

## Standard reading

```
Use field-aware-paper-reader to explain <the attached PDF / DOI / exact title> at standard depth.
I am reading it to <purpose>.
```

## Quick triage

```
Give me a quick read of <paper>. I mainly want to know whether its main claim is well supported
and which sections are worth reading myself.
```

## Deep reading for a journal club

```
Do a deep reading of <paper> for a journal club. Cover every main-figure panel, write out the key
equations with every symbol defined, and separate demonstrated problems from plausible concerns.
Put the result in a document I can share.
```

## Focus on the method

```
Read <paper> with the <statistics / machine-learning / ...> lens for the method and the
<application field> lens for the results. Focus on the assumptions behind <method name> and when
they would fail on data like <brief description of your data>.
```

## Focus on figures

```
Explain Figures <n>–<m> of <paper> panel by panel for a reader without a background in <field>:
what is plotted, what it shows, which claim it supports, and whether it is convincing.
```

## Follow-up work only

```
For <paper>, check both the journal and preprint versions and find up to five later papers that
extend, improve, apply or challenge it. For each, say what it changed and how strong the evidence is.
```

## 中文示例

```
用 field-aware-paper-reader 精读这篇论文（<附件 PDF / DOI / 标题>），标准深度。
我读它是为了 <目的>。请逐图解释主要结果，并解释关键公式里每个符号的含义。
```
